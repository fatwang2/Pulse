# Historical Pulse for Mac

The Mac edition through **0.15.8** retains its original MIT license. Its source
and release notes remain available in Git history, version tags, and GitHub
Releases; the current checkout maintains the Omarchy edition and Claude Code
plugin instead. The historical Mac edition receives no new features.

- [0.15.8 source and build instructions](https://github.com/fatwang2/Pulse/tree/v0.15.8)
- [Historical MIT license](https://github.com/fatwang2/Pulse/blob/v0.15.8/LICENSE)
- [Release notes and assets](https://github.com/fatwang2/Pulse/releases/tag/v0.15.8)
- [Historical free DMG](https://github.com/fatwang2/Pulse/releases/download/v0.15.8/Pulse-0.15.8.dmg)
- [Current Mac edition](https://www.pulseticker.app/)

Historical free DMG/ZIP assets and the existing Sparkle feed are preserved.
Users can decline a commercial update and keep their free version. Upgrading to
the commercial direct edition starts a **30-day full-feature trial**, followed
by a one-time purchase; update notes explain the purchase terms.

Current Mac and website source are private. Public Mac release tags and
GitHub-generated source archives refer to preserved public commits, not the
private source used to build commercial binaries.
