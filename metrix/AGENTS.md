# Pulse for Metrix.Bar

- One `.bar` file (`pulse.bar`, Metrix.Bar protocol 0) and its registry entry
  (`index.json`). Follow Metrix.Bar's docs (https://metrix.bar/docs/llms.txt):
  the .bar format, components and local API. The Worker is plain JavaScript in
  a CDATA block: no imports, no build step.
- `index.json` is generated by Metrix.Bar's `build.js` (see README) and carries
  the SHA-256 of the exact `pulse.bar` bytes. Bump the `<bar version>` and
  rebuild the index with every change to `pulse.bar`; a test checks they match.
  The install link points at `main`, so what lands there ships.
- Validate every change with the app's `POST /v0/validate` and `POST /v0/check`
  (fixtures and steps for the list, search, detail, light and dark, English and
  Chinese) before claiming it works. Look at the screenshots. Fixtures are
  limited to 2 MiB, so a check uses a trimmed catalog.
- The only hosts are `query1.finance.yahoo.com`, `data-api.binance.vision` and
  `www.pulseticker.app` (the symbol catalog, at most once a day). Search runs
  over that catalog on the user's computer: never send what they type to a
  search API. Its ranking is ported from `raycast/src/lib/search.ts` (the Mac
  app's SymbolSearchIndex); keep them in step. The only API beyond fetch is
  `$metrix.openURL` on a Pulse link, on a click. Keep README, `<docs>` and code
  in step on hosts, storage and behavior.
- Promote Pulse for Mac only (the footer link, the detail card, the tray menu,
  the README); name no other edition. Links carry `utm_source=metrixbar`.
- Respect Yahoo cooldowns; never show cached data as fresh or an unknown delay
  as real time. Crypto never waits on Yahoo.
- Sizes, colors and layout follow Pulse for Mac's watchlist within Metrix.Bar's
  native components; the interface is English and Chinese.
- Never put a Metrix.Bar local API token in this repository, a fixture or a log.
